# Классификатор обращений

Небольшой скрипт разбирает 5 готовых обращений из файла `messages.txt`.
Для каждого обращения он печатает категорию и черновик ответа на русском языке.

Категории:

- `справка` — вопросы о получении информации или порядке действий;
- `жалоба` — сообщения о проблемах или неудобствах;
- `другое` — остальные обращения.

## Как запустить

Нужен Node.js 18+.

```bash
node classify_messages.js
```

## Что получилось

Скрипт использует простые правила по ключевым словам. В текущем наборе обращений он определяет:

- справка о месте учёбы — `справка`;
- очередь и холодная еда в столовой — `жалоба`;
- запись на консультацию — `другое`;
- пропавший Wi-Fi в корпусе B — `жалоба`;
- парковка для гостей — `справка`.

LLM и внешние зависимости не нужны, поэтому проект можно быстро запустить локально и загрузить в репозиторий команды.
